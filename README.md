# 外幣兌換率工具 | HIS Tools

> 實時外幣兌換率查詢 + 夾錢計算工具

## 功能

### 1. 走馬燈匯率顯示
- 自動輪流顯示 100 HKD = 各常用貨幣
- 每 3 秒切換
- 顯示國旗、貨幣名稱、單價匯率

### 2. 夾錢計算
- 輸入總金額、幣種、人數
- 一鍵計算每人應畀
- 自動換算 6 種幣種（CNY/HKD/USD/EUR/JPY/TWD）

### 3. 常用匯率列表
- HKD 基準
- 5 種常用貨幣：CNY, USD, EUR, JPY, TWD

## 數據來源

- **Frankfurter API**（完全免費，唔使 API Key，無限制）
- 數據來自歐洲央行參考匯率
- 每日更新

## 技術

- Mobile Friendly 設計
- 深色主題
- CORS 代理 fallback
